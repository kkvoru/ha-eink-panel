# E-Ink Panel for Home Assistant

Компактная панель Home Assistant для старых электронных книг и браузеров.
Разработана для ONYX BOOX Monte Cristo 2, но может работать и на других
устройствах с устаревшим браузером.

Панель показывает:

- дату;
- текущую погоду и оригинальную иконку Яндекс Погоды;
- ветер и пять ближайших часов прогноза;
- температуру, влажность и уровень CO₂ в помещении;
- состояние домофона или замка в виде тумблера;
- состояние пылесоса и кнопки-иконки запуска/паузы, остановки и возврата на базу
  (если задан `vacuum_entity`).

Страница автоматически подгоняется под доступную высоту и не требует
прокрутки. Для открытия замка необходимо два нажатия в течение пяти секунд,
закрытие выполняется одним нажатием.

## Локальный предпросмотр

Для проверки внешнего вида не нужны push, релиз и установленный Home Assistant.
Нужен только Python 3.10 или новее, без дополнительных пакетов.

В Windows дважды нажмите `preview.cmd` либо выполните из папки проекта:

```powershell
python tools/preview.py --open
```

Откроется [локальный предпросмотр](http://127.0.0.1:8765/). Изменяйте
`custom_components/eink_panel/panel.html` и сохраняйте: предпросмотр автоматически
перезагрузится. Ширину и высоту области можно менять прямо над панелью;
начальный размер — 540 × 720 CSS-пикселей. Это пример размера, а не эмуляция
браузера электронной книги.

Погода и датчики используют демонстрационные данные; домофон и пылесос меняют
только состояние макета. Иконки берутся из встроенного SVG-набора интеграции.
Для изменения примеров данных откройте `tools/preview.py` и затем перезапустите
сервер. Проверку реальных данных HA и поведения старого браузера по-прежнему
нужно выполнять на устройстве.

Остановка сервера: `Ctrl+C` в его окне. Если порт занят, используйте
`python tools/preview.py --port 8766 --open`. Сервер доступен только на этом компьютере.

## Установка через HACS

1. Откройте `HACS -> Интеграции`.
2. В меню с тремя точками выберите `Пользовательские репозитории`.
3. Добавьте `https://github.com/kkvoru/ha-eink-panel` с типом `Интеграция`.
4. Найдите `E-Ink Panel` и нажмите `Скачать`.
5. Перезапустите Home Assistant.

Добавьте в `configuration.yaml` настройки по образцу:

```yaml
eink_panel:
  access_key: "REPLACE_WITH_A_LONG_RANDOM_KEY"
  weather_entity: weather.your_weather
  temperature_entity: sensor.room_temperature
  humidity_entity: sensor.room_humidity
  co2_entity: sensor.kit_mt8057s_co2
  lock_entity: lock.your_lock
  lock_label: "Домофон"
```

Замените все значения на собственные. Ключ должен быть длинным и случайным.
Параметр `co2_entity` необязателен: по умолчанию используется
`sensor.kit_mt8057s_co2`. При недоступном датчике CO₂ отображается прочерк.
После изменения конфигурации выполните проверку YAML и перезапустите Home
Assistant.

Панель будет доступна по адресу:

```text
http://HOME_ASSISTANT_ADDRESS:8123/eink-panel?key=YOUR_ACCESS_KEY
```

## Управление пылесосом

Добавьте в существующий раздел `eink_panel:` в `configuration.yaml`:

```yaml
  vacuum_entity: vacuum.your_vacuum
```

Укажите идентификатор пылесоса из Home Assistant, проверьте YAML и
перезапустите Home Assistant. На главном экране появится блок «Пылесос».
Без этой настройки блок скрыт, прежняя конфигурация продолжает работать.

Кнопки вызывают стандартные действия Home Assistant: `vacuum.start`,
`vacuum.pause`, `vacuum.stop` и `vacuum.return_to_base`. «Начать» также
возобновляет уборку после паузы. Слева в строке показаны название и статус,
справа — три иконки: запуск (во время уборки заменяется паузой), стоп и домик
для возврата на базу. Неподдерживаемые команды и управление
недоступным устройством отключены. Во время отправки команды повторное
нажатие блокируется. Статус проверяется каждые 15 секунд отдельно от погоды.
После сообщения об отсутствии ответа проверьте статус перед повтором команды:
пылесос мог её получить. Заряд батареи пока не отображается.

Описание действий: [документация Home Assistant](https://www.home-assistant.io/integrations/vacuum/).

## Переход с ручной установки

Добавьте репозиторий в HACS и скачайте `E-Ink Panel` поверх существующей
установки. Раздел `eink_panel:` в `configuration.yaml` сохраняется без
изменений. После установки перезапустите Home Assistant.

## Обновления

HACS отслеживает выпуски GitHub и показывает новую версию как обычное
обновление Home Assistant. После установки версии с изменениями Python-кода
перезапустите Home Assistant.

Для выпуска новой версии:

1. Зафиксируйте и отправьте изменения в ветку `main`.
2. Откройте [Actions → Release](https://github.com/kkvoru/ha-eink-panel/actions/workflows/release.yml).
3. Нажмите **Run workflow**, выберите ветку `main` и тип повышения версии:
   - `patch`: исправления, например `0.5.1` → `0.5.2`;
   - `minor`: новые возможности, например `0.5.1` → `0.6.0`.
4. Подтвердите запуск кнопкой **Run workflow**.

Workflow выполняет проверки HACS, Python и JSON, повышает `version` в
`custom_components/eink_panel/manifest.json` в отдельном коммите релизного тега,
отправляет только тег,
затем создаёт GitHub Release. После этого HACS сможет обнаружить обновление.
Ручной запуск разрешён только из `main`. Релиз содержит состояние ветки
на момент запуска workflow. Следующий номер вычисляется по наибольшей
версии среди существующих тегов `vX.Y.Z` и локального `manifest.json`.

Workflow не добавляет коммиты в `main`, поэтому после выпуска не нужно
подтягивать релизный коммит перед следующей отправкой. Версия в `main`
может отставать от релиза; в релизном теге она соответствует номеру выпуска.
Ручная отправка тега `vX.Y.Z` также поддерживается; номер должен совпадать
с `version` в `manifest.json`.

## Полноэкранный режим ONYX BOOX

Во встроенном браузере откройте меню справа сверху, затем
`Настройки -> Лаборатория Google` и включите режим работы без панели
инструментов.

## Безопасность

В репозитории нет ключей доступа, локальных IP-адресов и пользовательских
идентификаторов сущностей. Не добавляйте в GitHub свой настоящий
`configuration.yaml` или адрес панели с ключом.

Панель рассчитана на использование только внутри доверенной локальной сети.
Не публикуйте её порт в интернете без отдельной защиты.
